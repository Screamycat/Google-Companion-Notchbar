### Google-Companion Notchbar v0.0.2

- **Windows Autostart on Boot Fix**:
  - Fixed Windows failing to launch the app on system startup caused by unquoted file paths with spaces in the Windows Run registry.
  - Added native quoted path registration (`"C:\...\Google-Companion Notchbar.exe"`) with automatic legacy key cleanup.
  - Added self-healing migration on launch: automatically detects and upgrades any unquoted registry key from existing installations.
- **Companion Defaults**:
  - Default companion name changed to "Companion".
  - Default companion color set to clean Pure White (`#ffffff`).
- **Tray & Language Alignment**:
  - Set default tray menu and tooltip to English `Google-Companion Notchbar`.
- **Release & Updater Reliability**:
  - Streamlined release packaging and in-app updater delivery.
