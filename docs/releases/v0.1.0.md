### Google-Companion Notchbar v0.1.0

- **Gemini AI Assistant & Living Companion**:
  - Integrated intelligent Gemini AI Assistant directly into the Notch dock with real-time SSE streaming.
  - Real-time Companion emotional reactions synchronized to AI responses: BMO reacts to inline emotion cues (`[[Happy]]`, `[[Curious]]`, `[[Thinking]]`, `[[Vibing]]`, `[[Excited]]`, `[[Winking]]`, `[[Laughing]]`, `[[Proud]]`, `[[Sleepy]]`, `[[Sad]]`) alongside live emotion status badges.
  - Multi-model selection: Choose between **Gemini 2.5 Flash Lite**, **Gemini 2.5 Flash**, **Gemini 2.5 Pro**, and **Gemini 2.0 Argon (Thinking Experimental)**.
  - Adaptive dynamic height expansion: Chat window smoothly expands up to 400px as conversations grow, maintaining its expanded height across tab navigation.
  - Secure Google Sign-In with WebView2 cookie sync and seamless OAuth authentication.
- **Persistent Clipboard History & Configurable Limits**:
  - Clipboard history is now persisted to disk and survives app restarts and Notch reopening.
  - Configurable storage limits in **Settings → General → Clipboard History**: Customize Maximum Items (10–100, default 30) and Maximum Images (1–20, default 6) to keep memory footprint ultralight.
  - Deep deduplication: Fixed Windows Snipping Tool (`Win+Shift+S`) duplicate bug so screenshots register exactly once.
  - Automatic background pruning of cached screenshot PNGs when items are removed or cleared.
- **Interactive Global Shortcut Recorder**:
  - Replaced static dropdowns with an interactive keybind recorder in **Settings → General → Global Shortcuts**.
  - Record any custom key combination (e.g. `Ctrl + Alt + Space`, `Alt + A`, `Win + Z`, `Ctrl + Win + K`, or function keys like `F9`) for both **Open / Close Notch** and **Gemini Assistant**.
  - Dynamic hotkey registration and conflict prevention in Rust.
- **Dock Tabs & Dynamic World Polish**:
  - Saved custom dock tab order to disk permanently.
  - Cleaned up Dynamic World celestial body positioning so the Sun and Moon no longer collide with the Clipboard tab's filter pills or cards.
